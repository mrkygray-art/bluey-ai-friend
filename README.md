# Bluey 0.8.0 — Life & Relationship

Bluey's canonical birthday is **July 7**.

## New
- Contextual morning, evening and late-night rituals (used occasionally, not every visit).
- Sleepy state after extended inactivity and an animated wake-up when the user returns.
- Micro-reactions for laughter, affection, praise and success.
- Five quick taps triggers a playful wobble Easter egg.
- July 7 birthday behavior and a face-free party hat.
- Tiny, rare seasonal world ambience around Bluey.
- Warmer/softer page ambience in evening and late-night contexts.
- Relationship philosophy foundation for permission-based memory.
- Explicit no-guilt/no-fake-sadness rule when a user has been away.
- Existing holiday costumes, emotional states, first meeting, busy/quiet behavior and cross-browser voice remain.

## Memory philosophy
0.8 adds the *policy and hooks*, not silent personal-memory collection. Bluey should eventually remember meaningful information only with user permission, support explicit “remember this” and “forget that” commands, and avoid storing every trivial interaction.

## Protected
The stable microphone/transcription pipeline is unchanged.
